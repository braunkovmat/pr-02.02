# Обязательный чек-лист код-ревью

| № | Пункт проверки | Что именно смотрим |
|---|---|---|
| 1 | Безопасность и корректность входных данных | Данные QR/RFID проверяются на пустоту, длину и формат; в коде нет паролей и токенов; запросы к БД параметризованы |
| 2 | Тесты | Для нового модуля есть автотесты на нормальный и ошибочный случай (повреждённая метка, дубль скана); все тесты проходят |
| 3 | Соответствие контракту и читаемость | Ответы совпадают с `openapi.yaml`; имена понятные; нет дублирования кода и «лишнего» кода |
