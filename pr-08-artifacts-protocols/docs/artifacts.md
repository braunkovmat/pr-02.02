# Перечень артефактов проекта

АИС «Логистический хаб» (вариант 3): отслеживание перемещения посылок, приём сканирования QR-кодов и RFID-меток на складах, построение маршрутов доставки.

| Вид | Артефакт | Назначение в АИС | Формат и место хранения |
|---|---|---|---|
| Архитектурный | Диаграмма компонентов C4 и реестр ADR | Показывает модули хаба (приём сканов, трекинг, маршрутизация) и фиксирует принятые решения | PlantUML и Markdown в папке `/docs` |
| Контрактный | Спецификация `openapi.yaml` | Описывает API трекинга: `POST /scans`, `GET /parcels/{id}/track`, `POST /routes` | OpenAPI 3.0.3, корень репозитория |
| Кодовый / тестовый | Исходный код и автотесты (unit и интеграционные) | Реализация модулей, проверка разбора QR/RFID и расчёта маршрута | Репозиторий Git, папки `/src` и `/tests`, запуск в CI |
| Управленческий | Backlog задач и протокол код-ревью | Список работ по спринтам, статус задач, итоги проверки изменений | Доска задач и шаблон pull request |

Связь артефактов: контракт OpenAPI определяет, что должны делать сервисы; код и тесты проверяют соответствие контракту; архитектурные документы объясняют, почему система устроена именно так; управленческие артефакты показывают, кто и что делает.
