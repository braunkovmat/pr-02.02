# ПР №5. Стратегия ветвления Git Flow

Вариант 3: АИС «Интеграционный шлюз интернет-магазина».

- `Практическая_5_Браунков_02.02.pdf` — отчёт.
- `git-flow-scenario.sh` — сценарий из отчёта командами Git (Git Bash): `main`, `develop`, три `feature/*`, `release/v1.1`, `hotfix/payment-timeout`, теги `v1.0.0`, `v1.1.0`, `v1.1.1`.
- `git-log-graph.txt` — результат `git log --graph --oneline --decorate --all`, `git branch` и `git tag` после выполнения сценария.
- `shop-gateway.bundle` — готовый учебный репозиторий со всеми ветками и тегами. Открыть: `git clone shop-gateway.bundle shop-gateway`.
