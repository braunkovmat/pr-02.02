# ПР №9. Структура репозитория, .gitignore, .gitattributes

Вариант 3: АИС «Логистический хаб».

- `Практическая_9_Браунков_02.02.pdf` — отчёт.
- `AIS_LogisticsHub/` — структура репозитория: `src` (`Core`, `Infrastructure`, `UI`), `tests`, `docs` (`architecture`, `openapi`), файлы `.gitignore` и `.gitattributes` (в том числе правила Git LFS).
- `AIS_LogisticsHub.bundle` — исходный репозиторий из работы с первым коммитом `Chore: ...`. Открыть: `git clone AIS_LogisticsHub.bundle AIS_LogisticsHub_clone`.
